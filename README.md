## 🏆 Desafio Prático Oficial (Slide 13 / Moodle)
* **Problema Escolhido:** *Longest Substring Without Repeating Characters* (LeetCode #3)
* **Paradigma:** Janela Deslizante (Sliding Window) com Tabela Hash
* **Complexidade:** $O(N)$ tempo / $O(\min(N, \Sigma))$ espaço
* **Documentação & Código:** Veja `_Vault - Algoritmos/01 - Estruturas Lineares/Longest Substring Without Repeating Characters - LeetCode 3.md`.
